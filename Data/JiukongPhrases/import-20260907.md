# Reviewed phrase-pack additions, 2026-09-07

The maintainer supplied `JiukongZhuyin_常用詞庫_擴充版_20260907.json`,
confirmed that ChatGPT authored it, and explicitly requested correction during
integration into this project's default dictionary. This batch is attributed
to that maintainer-provided, ChatGPT-authored pack; it is not an import from an
outside dictionary or frequency list. No outside lexicon was used for review.

Source SHA-256: `503e748e01e778a7466bbfd5ee33eabe9fabdd7a4122c04792de19389b30d3c0`.

The pack contains 4,377 distinct phrase/reading pairs and no removals. Review
corrected or normalized 378 entries, then retained all 4,377 input entries as
corrected pairs: 2,293 were already represented or deduplicated within the
corrected batch, 14 already exist in the bundled government phrase sources,
and 2,070 were appended to `phrases.tsv`. The resulting
first-party lexicon has 5,368 pairs and 5,338 distinct phrase texts.
Existing rows and their tie-break order are preserved.

`import-20260907-corrections.tsv` records every changed input and its final
spelling/readings, including entries that deduplicated against existing rows.
The original user file is unchanged. Review covered phrase spelling and
contextual readings, not just whether each syllable parses. Examples include
平安, 晚安, 肚子, 發行, 充分, 機制, 回憶, 症狀, and 紮實.
Unattested conversational neutral tones were normalized to supported full
syllables; supported neutral tones and the existing documented 謝謝 variant
were retained. Taiwan readings of 期 and 究 were normalized in this batch.
This normalization does not assert that other regional readings are errors.

Every final character/reading pair is checked against the pinned CNS11643
character data and the existing first-party supplemental readings, with only
the already documented 謝謝 exception. No supplemental character readings,
frequencies, ranking overrides, or government phrase sources were added.
The normal builder includes these reviewed first-party rows in the default
SQLite dictionary and its first-party phrase-attestation signal.

The fourteen government duplicates remain government-attributed and are not
added to first-party phrase-attestation counts: 不怎麼樣, 中華民族, 二氧化碳, 人工智慧, 區域網路, 國定假日, 意想不到, 搜尋引擎, 絕大多數, 統一發票, 網路銀行, 網際網路, 西班牙語, 電子信箱.
